# For my Rapunzel

A personal, two-scene pixel-art love story for Ammu: a Kerala beach sunset and a cozy ATLA night.

All artwork is drawn in JavaScript using the Canvas API. Includes animated waves, gentle hair caresses, a golden retriever puppy, and responsive layouts. The site has no music or audio controls.

## Website

https://just-poet.github.io/for-my-rapunzel/

## Run locally

No installation or build is required. Open `dist/index.html` in a browser, or serve it with:

```sh
python -m http.server 4173 --directory dist
```

## Publish

Changes pushed to `main` publish `dist/` to GitHub Pages through the included workflow. The static files can also be hosted by any static website provider.
